# 設計決定ログ

ArticuLaterのプロダクト設計・UX設計において、**ユーザーと合意して確定した事項のみ**を記録する。

- 最上位の仕様は `docs/PRODUCT.md` とし、本ログはそれを具体化するものとする
- 未確定の事項は確定仕様として記載しない（「未決」と明示した場合のみ記載する）
- 決定を覆す場合は、既存の記述を消さずに新しい決定として追記し、どの決定を置き換えたかを明記する

## D1. テキスト選択とMarkの関係

**決定日**: 2026-09-29

### 決定

- **テキストを選択し終えた時点（マウスを離した時点）で、そのままMarkとして記録する。**
- Markのための追加操作（キー入力・ボタン押下・確認）は要求しない。
- 誤Markや通常のテキスト選択のために、以下の「逃げ道」を用意する。
  - 直前のMarkを即座に取り消せる（Undo）
  - 修飾キーを押しながらの選択は、Markにならない通常選択とする
  - Mark後もテキスト選択状態を残し、そのままコピーできる

### 理由

- PRODUCT.md の「選択 → Mark → 読書を継続」に最も忠実であり、「Markするか？」という判断を挟まない
- ArticuLaterはレビューのための閲覧ツールであり、選択の主目的はMarkである
- 誤Markのコストは「後で1件消す」だけだが、Markしそびれた反応は取り戻せない

### 前提・留意点

- 想定ユーザー（本プロダクトのオーナー）は主にマウスで読む。そのため、キーボード操作を前提としない取り消し手段が必要になる可能性が高い（D3で扱う）
- 「読みながら無意識に選択する」ユーザーでは誤Markが増えるリスクがある。プロトタイプ段階で実際に触って検証する

### 未決（後続の論点で扱う）

- マウスのみでMarkを取り消す手段（→ D3で決定）
- ダブルクリック・トリプルクリックによる選択をMarkとするか（→ D3で決定）
- 既存Markと重なる範囲を選択した場合の扱い
- Undo・通常選択に割り当てる具体的なキー

## D2. 表示形式とMarkの粒度

**決定日**: 2026-09-29

### 決定

- **Markdownはレンダリング表示のみとする。** ソース表示・表示切替はMVPでは提供しない。
- **Markはテキスト選択のみで行う。** コードブロック内・表のセル内もテキスト選択でMarkする。
  - 段落・表・コードブロック・画像などのブロック単位Markは、MVPでは提供しない。実際に使ってみて不便であれば後で検討する。
- **Mermaidは図としてレンダリングせず、コードブロックとして表示する。**

### 理由

- 読書体験を最優先するため、整形された表示で読めることを重視する
- 操作体系を「テキスト選択」の1つに保ち、覚えることを増やさない
- Mermaidをコードとして表示すれば、図の中身もテキスト選択でMarkでき、AIへ正確な箇所を渡せる

### 前提・留意点

- レンダリング表示上の選択を、元Markdownのどの位置に対応させるかは D5（紐付け方式）で扱う
- 画像そのものはMarkできない。画像について気になった場合は、前後のテキストをMarkする

## D3. Mark直後の反応とメモ

**決定日**: 2026-09-29

### 決定

- **Markした直後は、選択範囲がMarkとしてハイライトされるだけとする。** ポップアップ・ヒント・メモ入力欄などは一切表示しない。
- **メモは任意とし、以下の2か所から書ける。**
  - 本文上のMarkをクリックすると表示される小さなポップオーバー
  - Mark一覧
- **マウスでMarkを削除するときは、Markをクリックして開くポップオーバー内の削除ボタンを使う。** メモと削除の入口を1つにまとめる。
- **ダブルクリック（単語）・トリプルクリック（段落）による選択もMarkとする。** 「選択＝Mark」を例外なく一貫させる。

### 理由

- Mark直後に何かを表示すると、視界にUIが割り込み、「メモを書くべきか」という判断を誘ってしまう。ハイライトのみにすれば読書を中断しない
- メモ・削除は「必要なときだけ、ユーザーが自分からMarkに触れる」ことで行い、フィードバックを強制しない
- 主にマウスで読むユーザーでも、キーボードなしで取り消し・メモ・削除を完結できる
- トリプルクリックが、実質的に段落単位のMarkとして機能する

### 前提・留意点

- クリック（ドラッグなし）でMarkを開く操作と、Mark上から新たに選択を始める操作の区別は、D1で未決とした「既存Markと重なる範囲の選択」とあわせて検討する
